# aoe2vils

Calculation webapp tool for estimating villagers required and transition eco in Age of Empires II: Definitive Edition.  

Hosted on [aoe2vils.net](https://aoe2vils.net/)

All gather rates manually verified and tested in-game on patch 185872.

### Things I thought out would be nice to have (which you now have in aoe2vils.net)

- Integrated and useful calculation of niche incomes  
_Instead of figuring out how many burgundian relics we need to sustain unit productions, we can see how many fewer villagers on food we need to sustain units productions. Same logic for relics, Shu lumberjacks, Polish stone miners, etc._
![demo1](https://github.com/user-attachments/assets/b9bf6458-1966-438f-907a-e38295d9499a)

- Idle TC time indicator  
_Skip the head math of how many 25 seconds fit in your idle tc time, see immediately using this slider._
![demo2](https://github.com/user-attachments/assets/11a6797f-deed-497f-a656-bf366276c521)


- Custom user-defined values  
_Doesn't matter if I wasn't quick enough to update for a patch or a new DLC, plug that new unit's costs and creation time or new gather rates in yourself._

- See how much resources in arbitrary time or how many villagers to get defined amount of resources in arbitrary time  
_Either see age-up times or define time-span yourself._

### Some other nice things about aoe2vils.net
- no ads nor cookies, naturally privacy friendly and GDPR compliant
- no page scrolling, what you see is what you get
- no images, just 2 http requests and a fast load time

### Some not so nice things
- the UX for mobile users isn't great, aoe2vils.net is best on desktop
- it's still a bit overwhelming with the amount of checkboxes and dropdown menus
